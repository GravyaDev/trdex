### Lessons learned da promuovere nella KB

Vedere sezione "Lessons learned" del handoff file, 10 voci:
1. PowerShell `ssh-keygen -N '""'` crea passphrase `""` letterale
2. Termix SFTP editor resetta permessi a 666 on save
3. Hostinger API "attached" SSH keys sono metadata, non necessariamente filesystem sync
4. Docker CMD-SHELL default è sh (dash), non bash → `/dev/tcp` richiede `bash -c`
5. Qdrant image è Debian ma senza curl/wget/nc (solo bash)
6. FastAPI lifespan che query DB prima di assicurare schema crasha su fresh volume
7. Dockerfile copia solo quello che esplicita → COPY migrations/ è obbligatorio
8. Permission model multi-user Linux: setgid `2xxx` per shared workspace
9. Coolify 4.x UI + Traefik + LE è stable, non bypassarlo
10. Sessioni >6h mostrano context saturation, hard stop prima
